📱 InternVision ChatFlow

A clean & modern real-time chat application built with Flutter for the InternVision task.
Supports authentication, real-time messaging, online/offline status, typing indicator, animated UI, and Firebase backend.

👤 Authentication

Register / Login with email & password

Username selection

User online/offline presence tracking

💬 Real-Time Chat

1-to-1 real-time messaging

Message timestamps

Seen / Delivered system

Typing indicator

Send text & images

Smooth animations

Auto scroll

Delete message

Chat bubbles with clean UI

Storing all chat history in Firestore

🔍 Users List

Real-time users list

Online status (green dot)

Last message preview

Last message time

Animated transitions

Search by username
